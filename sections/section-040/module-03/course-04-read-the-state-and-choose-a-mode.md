# Read The State And Choose A Mode

When IPsec runs you read it in three places, and when it breaks the same places tell you why. Then you compare it with WireGuard and pick.

## Three places to read

- `cilium-dbg status` has an Encryption line that names IPsec and gives the number of keys and any errors.
- `cilium-dbg encrypt status` lists the decryption interfaces, the keys in use by SPI, the highest sequence number and the error counters.
- `ip xfrm state` and `ip xfrm policy` in the agent show the kernel objects. Counters in `ip -s xfrm state` show the packets and the bytes that each state handled.

## Common faults

| Symptom | Likely cause |
| --- | --- |
| The agent does not start encryption | The key line is malformed, or the Secret is missing |
| Traffic between two nodes fails, others work | A node holds the old key, or ESP (protocol 50) is blocked |
| Errors grow in `encrypt status` | Keys differ between nodes, or a sequence problem after a restart |
| Handshake-free but no traffic | A firewall drops ESP or UDP 4500 |

IPsec runs over ESP, an IP protocol, not over TCP or UDP. A firewall that allows only TCP and UDP drops it, so allow IP protocol 50 between the nodes.

## IPsec or WireGuard

| Question | IPsec | WireGuard |
| --- | --- | --- |
| Keys | You create and rotate the Secret | Generated by each node |
| Setup | More steps, kernel IPsec modules | One setting, kernel module from Linux 5.6 |
| Standards | Common in compliance rules and FIPS settings | Not an option where a standard names IPsec |
| Operation | More to watch: SPI, ESP | Fewer parts: device, peers |
| Port | IP protocol 50 (ESP) | UDP 51871 |

Choose IPsec when a rule or a tool requires it, or when you need an algorithm that WireGuard does not offer. Choose WireGuard when you do not have such a need: it has less to operate.

## Common pitfalls

> [!WARNING]
> Do not switch a running cluster from one mode to the other without a plan. Both modes are not meant to run together. Test the change in a copy, expect a short disruption and have a way back.
