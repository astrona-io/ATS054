# Sidecar-based versus Sidecarless Architectures

This section covers sidecar-based versus Sidecarless Architectures. It develops sidecar And Shared-Proxy Architecture Tradeoffs through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Compare per-Pod sidecars with shared node proxy processing.

- Evaluate resource, upgrade and failure-scope tradeoffs.
- Distinguish architecture labels from security guarantees.
